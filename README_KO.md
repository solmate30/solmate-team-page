## 📖 1. 프로젝트 개요 및 비전

**Solmate**는 현대 사회의 파편화된 두 가지 문제인 **'유휴 공간(지방 소멸로 인한 빈집)'**과 **'사회적 고립(1인 가구 및 독거노인의 외로움)'**을 동시에 해결하기 위해 탄생한 플랫폼입니다.

AI의 압도적인 확장성을 활용해 24시간 정서적 동반자가 되어주고, Web3의 투명성을 통해 빈집 재생과 사회적 자본의 흐름을 투명하게 증명하여 두 '빈칸'을 혁신 기술로 연결합니다.

## 🎯 2. 해결하고자 하는 문제 (Core Problem)

* **물리적 빈칸 (The Empty Spaces)**: 인구 감소 및 고령화로 인한 지역 사회의 빈집 급증과 자원 방치 문제.
* **정서적 빈칸 (The Empty Hearts)**: 1인 가구 및 독거노인 등 사회적 연결망 약화로 인한 정서적 고립, 우울증 및 고독사 문제.
* **신뢰의 부재**: 복지 예산, CSR 기부금, 빈집 수리 자금이 정확히 어떻게 쓰였는지 투명하게 추적하고 임팩트를 측정하기 어려운 한계.

## 💡 3. 솔루션 & 핵심 경쟁력 (UVP)

Solmate는 단순한 챗봇이나 부동산 플랫폼을 넘어선 **투명한 임팩트 오퍼레이션**을 제공합니다:

1. **AI 기반 스케일러블 케어**: 물리적 한계를 극복한 감성 AI '솔이'를 통해 수만 명의 독거인에게 24/7 맞춤형 대화를 제공합니다. 대화 중 위험 단어 등 이상 징후 감지 시 지자체 및 보호자와 연계합니다.
2. **Web3 기반 투명성 증명 (Creditcoin & BondBase)**: 스마트 컨트랙트를 통해 기부금이나 복지 예산이 빈집 수리 및 독거인 지원에 어떻게 쓰였는지 **100% 온체인 기록**합니다. 이를 통해 지자체와 기부자에게 "돈이 제대로 쓰이는가?"에 대한 불신을 원천 차단합니다.
3. **Raise-to-Earn (임팩트 토크노믹스)**: AI와의 꾸준한 긍정적 대화나 빈집 재생 크라우드펀딩에 참여하는 사용자에게 보상을 제공하여 지속 가능한 생태계를 구축합니다.

## 🛠 4. 기술 스택 및 아키텍처

### 프론트엔드 & UI
* **프레임워크**: Next.js 16 (App Router), React 19
* **스타일링 & 애니메이션**: Tailwind CSS v4, Framer Motion
* **3D 인터랙티브 UI**: React Three Fiber, Drei (메인 페이지 파티클 상호작용)
* **상태 관리**: Zustand 5

### AI & 데이터 레이어
* **AI 모델**: OpenAI `gpt-4o-mini` (서버 사이드 스트리밍 적용)
* **실시간 공공 데이터**: 공공데이터포털 REST API (KOSIS 한국통계, 한국농어촌공사 빈집 정보) 연동 및 RSC 바탕의 Route Caching 최적화.

### Web3 & 백엔드 (연동 대기중)
* **Web3/블록체인**: 자금 흐름 추적 및 스마트 컨트랙트 관리를 위한 Creditcoin 3.0, BondBase 도입 예정.
* **데이터베이스**: 엣지 최적화 DB (Turso / SQLite)

## 🚀 5. 로컬 실행 가이드

Solmate 프로젝트를 로컬에서 구동하기 위한 가이드입니다.

### 사전 준비
* Node.js (v18 이상)
* npm, yarn, pnpm 또는 bun

### 설치 및 실행

1. **레포지토리 클론:**
   ```bash
   git clone https://github.com/your-repo/solmate.git
   cd solmate/web
   ```

2. **의존성 모듈 설치:**
   ```bash
   npm install
   # 또는 yarn install
   ```

3. **환경 변수 설정 (`.env.local`):**
   OpenAI API 키, 공공데이터포털 API 키 등 필요한 환경 변수를 설정합니다. (`web` 디렉토리 내부)

4. **개발 서버 실행:**
   ```bash
   npm run dev
   # 또는 yarn dev
   ```

5. **접속 확인:**
   브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 프로젝트를 확인합니다.
   - AI 반려봇 채팅은 `/chat` 경로에서 확인할 수 있습니다.
